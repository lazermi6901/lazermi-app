# LAZERMI — GitHub iPhone Flat

Version sans sous-dossiers, prévue pour un dépôt GitHub depuis Safari sur iPhone.

## Import
Sélectionnez `index.html`, `manifest.webmanifest` et `README.md`, puis envoyez-les dans la racine du dépôt.

## Important
Le catalogue fourni est une démonstration de jeu avec des objets fictifs neutres.
Le panneau Créateur de cette démo sauvegarde localement sur l'appareil.
Pour une administration réellement privée et synchronisée entre appareils, connecter ensuite Supabase Auth + RLS.
